# SidekickAI

Ask questions about any webpage or PDF using AI.

Drop a PDF in the Settings tab, or just click the extension and ask about the page you're on. 
The answer pulls from both the page content and your uploaded documents using RAG.

## Tech Stack

**Backend:** Python, FastAPI, ChromaDB, sentence-transformers (all-MiniLM-L6-v2), Your LLM API Key

**Extension:** Chrome Extension MV3, HTML, CSS, JavaScript

**Infrastructure:** Persistent vector store, RAG pipeline with semantic search
